04The showpiece — Canvas UI glass-object

npx shadcn add @canvas-ui/glass-object-react
Passport hero vessel

Category glyph traced and extruded into refracting glass — tint #6e2de4, highlight #d99cff, ior 1.6, dispersion 1.2. Drag to orbit when live.

Deployment rules
  • Feature-flagged per route; static glyph art is the SSR / no-WebGL / reduced-motion fallback.
  • Lazy-loaded below the fold threshold; `three` is already installed.
  • The glass never carries data, copy, or evidence — orientation only.
  • One glass object on screen at a time.
