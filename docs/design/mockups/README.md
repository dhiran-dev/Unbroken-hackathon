# PulseRank mockups

Mockups are grouped by authority so reference material cannot be mistaken for
the product contract.

## Approved

`approved/` contains the owner-approved route references with normalized names:

- `home.png`
- `explore.png`
- `product-passport.png` and `product-passport-alternate.png`
- `leaderboards.png` and `leaderboards-alternate.png`
- `compare.png` and `compare-alternate.png`
- `my-pulse.png`
- `changes.png`
- `live-data.png`

The binding implementation rules remain in the root [DESIGN.md](../../../DESIGN.md).

## Prototypes

`prototypes/` contains historical HTML/CSS explorations and rendered reference
images. They are design-development tools, not application routes or build
inputs.

## Local examples

`examples/` contains non-authoritative generated references. It is intentionally
ignored to avoid adding a large working archive to repository history.
