## Template observations

- Single template family across /caffeine-content/: `db-card` hero card (Caffeine value + per-serving text + fl oz/mls unit toggle via `#serving-size[data-floz][data-mls]` + strength badge), optional Calories card, optional Sugar card, Ingredients section, comparison bar chart, references block.
- Calories and Sugar cards are OPTIONAL: all six mint/gum/candy pages omit both.
- Caffeine value is not always numeric: heat-esp renders the literal string "Unknown mg".
- Strength badges observed: LOW, MODERATE, HIGH, EXTREME, DANGEROUS (heat-esp), and CAFFEINE FREE exists in the site JS (`calc_Level`) for 0 mg items.
- Discontinued flavours are struck through with `<s>`/`<strike>` elements (bawls, red-bull-editions).
