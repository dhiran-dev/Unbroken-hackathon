# Domain docs

UNBROKEN is a single-context repository.

Before changing the product, read:

- `CONTEXT.md` for canonical domain terms.
- Relevant records in `docs/adr/` for hard-to-reverse decisions.
- `docs/product/sf-citywide-spec.md` for the approved visible behavior.
- `docs/engineering/README.md` for interfaces, ownership, gates, and ticket links.

Use glossary terms in code, tests, issues, documentation, and rider copy. If a new domain term is unavoidable, define it in `CONTEXT.md` without implementation details. If work conflicts with an accepted ADR, stop and surface the conflict rather than silently overriding it.
