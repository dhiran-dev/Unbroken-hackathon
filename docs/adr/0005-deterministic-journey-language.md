# Generate journey instructions deterministically

Status: accepted

Journey steps, warnings, change summaries, and commute emails are produced from versioned templates and validated journey data. An LLM cannot create rider instructions because variable wording can overstate incomplete accessibility evidence and makes repeated plans difficult to compare. Fireworks remains confined to structured advisory review of scraper-healing previews.

## Consequences

Identical input and trusted evidence produce identical instructions and an internal change fingerprint. Rider wording clearly separates confirmed, unknown, blocked, older, and unavailable evidence without exposing implementation vocabulary.
