# Require source trust before publication

Status: accepted

Every official source crosses a deterministic validation seam before its facts can change a journey or public status. The previous trusted snapshot remains active after a failed or suspicious refresh; missing accessibility data stays unknown, layout drift produces no service event, and a healed preview must pass the production contract before an operator can approve it. This favors conservative continuity over publishing the newest unverified response.

## Consequences

Checked time, source-updated time, freshness, and official-source link travel with public facts. Fireworks review remains advisory and cannot publish, approve, or bypass a deterministic failure.
