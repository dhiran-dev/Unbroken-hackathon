## Local working archives

The following paths are organized but intentionally ignored by Git:

- `plans/` — local execution plans and archived duplicates;
- `archive/sessions/` — session progress and completion notes;
- `design/mockups/examples/` — non-authoritative visual examples;
- `design/references/` — bulky landing-page and game reference assets; and
- `presentations/` — generated presentation projects and snapshots.

These archives must not be used as runtime inputs or release artifacts.
